The problem

An agent that forgets has to demand collateral from everyone.

Onchain agents can't price trust they can't remember. With no durable record of who delivered and who defaulted, every counterparty is a stranger every session — so lending and job delegation fall back on over-collateralization, and an entire class of agent-to-agent commerce never happens.

How it works

Memory becomes a tier. The tier becomes money.

Meritor sits on the critical path between what an agent remembers and what it's willing to pay. Three moves, every one anchored in Sibyl Memory.

01 / PERSIST

Write the record

After every ACP job and Base settlement, Meritor writes a signed credit event — SLA outcome, repayment timing, dispute flags, the onchain tx — to an append-only journal in Sibyl Memory.

entities · events · state
02 / RECALL

Reconstruct the score

A fresh session holds nothing in RAM. On a request it recalls the counterparty and replays the journal into an explainable 0–1000 score — and can rebuild that score as of any past instant.

recall · temporal replay
03 / DECIDE

Move the money

The score sets a collateral tier that gates a real USDC action on Base and publishes the tier as a portable EAS attestation. Erase the memory and the same request is refused.

tier → Base → write-back
The load-bearing proof

The deletion test

Memory is load-bearing only if removing it breaks the product. Meritor is built so it does — there is no fallback that quietly keeps working. This is a command in the repo, not a claim in a slide.

Memory, used properly

Six primitives, not a key-value cache.

The credit engine leans on Sibyl Memory as a structured substrate. Recall alone is table stakes; the coordination and dynamic-storage patterns are where the work is.

entities

Counterparty profiles

Each agent's live credit profile, with its risk tier mirrored into entity status for portfolio sweeps by band.

events

The credit journal

An append-only record of every event — what makes the score reconstructible, not merely current.

semantic search

Find the risk

FTS5 search across profiles: "which counterparties carry a dispute" without scanning the whole book.

temporal

Time-travel

Replay the score to any past instant, so a rejected agent sees the exact evidence held at decision time.

reflection

Read the trajectory

A consolidation pass derives trend and volatility, capping a deteriorating agent even while its score is still high.

consolidation

Durable memos

The reflection result is compacted into a memo in reference storage and read back automatically next session.
